# 接点接触电阻在线监测系统 · 功能实现分析

对照 Java 源码整理的课题报告讲义。页面按功能拆开说明：每项做了什么、在哪个类里、具体怎么实现。

分析的源码在 `docs/source/`：

- `ZzhejiPanel.java` 测试主界面与状态机
- `DianZu00000.java` 三路接触电阻采集
- `JiaoL.java` 电流采集
- `ExecuteCommon.java` 数据库访问（两份原文件内容相同）

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43217](http://127.0.0.1:43217)。

## 这套软件在做什么

上位机通过 COM3（9600，Modbus-RTU）按凸轮节拍交替读取三路接触电阻和一路电流，用双 Y 轴折线图显示“次数—电阻/电流”，并在电阻超限、电流超限、凸轮超时或达到设定次数时停机报警。试验曲线和故障记录写入数据库，可按测试编号回放。
