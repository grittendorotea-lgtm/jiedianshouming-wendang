# 接点接触电阻在线监测系统 · 功能实现分析

对照 Java 源码整理的课题报告。前十五节写单工位基础实现，第十六节单独写 4 拖 1 多工位方案。正文含摘要、操作流程、一拍通信时序和分层流程图。

分析的源码在 `docs/source/`：

- `ZzhejiPanel.java` 基础版测试主界面与状态机
- `DianZu00000.java` 三路接触电阻采集
- `JiaoL.java` 电流采集
- `ExecuteCommon.java` 数据库访问（两份原文件内容相同）
- `ZzhejiPanel-20260811.java` 4 拖 1 拓展面板（第十六节）
- `SixMeterInstrumentReader.java` COM5 八表统一读取器（第十六节）

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43217](http://127.0.0.1:43217)。打印稿在 [http://127.0.0.1:43217/print](http://127.0.0.1:43217/print)。可粘贴进 Word 的正文在 `docs/课题报告-功能实现分析.md`。

## 这套软件在做什么

基础版上位机通过 COM3（9600，Modbus-RTU）按凸轮节拍交替读取三路接触电阻和一路电流，用双 Y 轴折线图显示“次数—电阻/电流”，并在电阻超限、电流超限、凸轮超时或达到设定次数时停机报警。

4 拖 1 方案改为一台上位机同时管理四台监测设备：COM4 专访 PLC，COM5 统一轮询八台仪表，保护、曲线和故障台账按设备号隔离。
