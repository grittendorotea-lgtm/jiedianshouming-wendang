# 接点接触电阻在线监测系统 · 功能实现分析

对照 Java 源码整理的课题报告。全文 15 节，每一节先写基础实现，再写四工位八表拓展与技术难点。

分析的源码在 `docs/source/`：

- `ZzhejiPanel.java` 基础版单工位主界面与状态机
- `ZzhejiPanel-20260811.java` 四工位拓展面板（监测设备 1～4）
- `SixMeterInstrumentReader.java` COM5 上轮询八台仪表（电流 01～04、电阻 05～08）
- `DianZu00000.java` 基础版三路接触电阻采集
- `JiaoL.java` 基础版电流采集
- `ExecuteCommon.java` 数据库访问（这批文件仍是单记录接口；四工位面板已按分设备方法调用）

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43217](http://127.0.0.1:43217)。打印稿在 [http://127.0.0.1:43217/print](http://127.0.0.1:43217/print)。可粘贴进 Word 的正文在 `docs/课题报告-功能实现分析.md`。

## 这套软件在做什么

基础版上位机通过 COM3（9600，Modbus-RTU）按凸轮节拍交替读取三路接触电阻和一路电流。拓展版改为双总线：COM4 专访 PLC，COM5 由统一读取器后台轮询八台仪表；四个页签并行做寿命试验，保护、曲线和故障台账都带设备号。
